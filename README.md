# porty-the-builder

Hello! This is Ishi building Porty, what I hope to be a no-code digital portfolio building site for those who want a quick showcase but don't have much time.

My goals for this are to:
1. Have distinct important portfolio site sections (About Me, Projects, Experience, Education)
2. Have multiple standard templated layouts for each section (such as Projects, Experience, Education, etc.) in forms of things like carousel, timeline, grid
3. Have user be able to reorder these sections to their will
4. Allow user to customize design aspects like fonts and colors

This is also admittedly my practice with Claude Code, which I hope to refine my usage more of as I go! I hope to make smarter and more efficient prompts, and read and review code more quickly. 

If you're interested in this project in anyway, please reach out !! Would love to connect with more builders (and builders building builders) out there.
